# Lists in Compose
Source: https://developer.android.com/develop/ui/compose/quick-guides/content/video/lists-in-compose

Explore Compose's lazy components, which make it easy to display lists of items. Learn how to show different item types, implement sticky headers, and programmatically control or react to the scroll-position changes.

## Key points
- The `LazyColumn` API is built as a DSL, differing from other layouts in Compose.
- Use `LazyColumn` to display items visible on screen.
- Use the `items()` function to pass items. The lambda defines the content of each of the items, so you can keep the existing code.
- To display many different item types, use the `groupBy` function.
