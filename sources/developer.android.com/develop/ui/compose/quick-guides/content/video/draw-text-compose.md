# Draw text in Compose
Source: https://developer.android.com/develop/ui/compose/quick-guides/content/video/draw-text-compose

See how to use Compose APIs specifically designed to draw text on a canvas. This segment shows the code to draw an emoji font in a rounded rectangle.

## Key points
- In Compose, you can draw text on a canvas by creating a text measure and calling `drawText`, resulting in the measuring string.
- You can also customize the text size, alignment, and other properties.
