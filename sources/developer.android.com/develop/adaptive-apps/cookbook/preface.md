# Adaptive app cookbook
Source: https://developer.android.com/develop/adaptive-apps/cookbook/preface

Android provides all the ingredients for five-star adaptive apps. The recipes in this cookbook select and combine choice ingredients to solve specific development problems. Each recipe includes best practices, quality code samples, and step-by-step instructions to help you become an adaptive app top chef.

## Star ratings

The recipes are star rated based on how well they align with the Adaptive app quality guidelines.
