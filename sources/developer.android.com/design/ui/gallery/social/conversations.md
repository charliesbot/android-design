# Social media conversations
Source: https://developer.android.com/design/ui/gallery/social/conversations

Display a list of conversations side by side with conversation details to make keeping up with all the latest messages. Users can scan the list, then simply select a conversation to see what all the talk is about.

## Implement a list-detail

A list-detail layout enables users to explore lists of items that have descriptive, explanatory, or other supplementary information—the item detail.
