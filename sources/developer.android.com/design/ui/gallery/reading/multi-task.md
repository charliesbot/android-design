# Multi task while reading
Source: https://developer.android.com/design/ui/gallery/reading/multi-task

Distinctive features and capabilities not possible on small screen devices.

With multi-window mode on expansive displays, readers can pore over weighty tomes in one window while taking notes, checking facts, or sharing observations in another window, in another app, instantly.
